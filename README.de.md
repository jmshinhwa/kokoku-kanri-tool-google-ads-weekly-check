# Anzeigenmanagement Software | Google Ads Wochencheck: verschwendete Suchbegriffe

Anzeigenmanagement Software — ein Skript im eigenen Google-Ads-Konto findet jede Woche verschwendete Suchbegriffe und trägt nur die freigegebenen Ausschluss-Keywords ein

Anzeigenmanagement Software für Google Ads: Das Skript wird einmal unter Tools → Skripte eingefügt und prüft jede Woche die Suchbegriffe der letzten 7 Tage. Kein OAuth, kein Developer-Token, kein Konto-Zugang für Dritte.

• Beispiel (erfundener E-Bike-Akku-Shop, 7 Tage): Von 676,40 € Kosten gingen 122,75 € (18,15 %) an Suchbegriffe mit 0 Conversions, die je mehr als die 48,31 € Kosten pro Conversion ausgaben.
• Erst Freigabe, dann Änderung: Nur angehakte Ausschluss-Keywords ([genau passend] / "passende Wortgruppe") werden beim nächsten Lauf eingetragen, mit datiertem Änderungsprotokoll. Ohne Freigabe ändert sich nichts.
• Deutsche CSV-Exporte (Semikolon, 1.234,56 €), Groß-/Kleinschreibung zusammengefasst, Bericht und Warn-Mail auf Deutsch.
• Warum monatlich: Jeder Wochencheck wird mit der gespeicherten Vorwoche verglichen (neu verschwendet · behoben); die Warn-Mail kommt nur in Wochen mit Geldverlust. Verlauf und Änderungsprotokoll bleiben gespeichert.
• Bei Kündigung enden Wochencheck, Warn-Mail und Freigabe → Eintragen. Der kostenlose CSV-Check einer Woche im Browser bleibt.
• Datenschutz: Der CSV-Check läuft nur im Browser. Das Skript sendet nur Suchbegriff- und Kampagnenzahlen (keine Anzeigentexte, Zugangsdaten oder Kundendaten). Speicherung bei Cloudflare (nicht auf die EU beschränkt), kostenlos 30 Tage, Pro bis 104 Wochen; „Daten löschen“ entfernt alles sofort.

Kostenlos: Beispiel, CSV einfügen (Rechnung im Browser), Skript für 1 Konto mit der neuesten Woche.
Pro: Wochenverlauf, Vorwochenvergleich, Freigabe → automatisch eintragen, Änderungsprotokoll, Warn-Mail, CSV, Druck/PDF. Agentur-Tarif bis 10 Konten.

Als Werbeanzeigen verwalten Software und Google Ads Kampagnen verwalten Tool. Keine Ausschlüsse für Performance Max, Shopping oder Display, keine Gebots- oder Budgetänderungen. Kein Versprechen höherer Ergebnisse.
